# OneTen: слой анимаций v5 и новые блоки

`patch.py` дописывает в готовые страницы `oneten-site/` анимации, SEO-тексты, блоки с фото и компактный блок «Подход» на главной. Повторный запуск заменяет вставленные блоки и не дублирует их.

```
python3 oneten-build/patch.py oneten-site
python3 .claude/skills/seo-verify/check.py oneten-site
```

## Файлы

| Файл | Что внутри |
|---|---|
| `motion.css`, `motion.js` | анимации: шаги, сравнение, галочки, годы истории, иконки ниш, счётчики, FAQ, обложки, перетаскивание лент, карта в контактах, мерцание пустых фото, отклик на телефоне |
| `content.py` | SEO-тексты, meta description, подписи блоков с фото |
| `patch.py` | вставка всего этого в страницы |

## Как поставить фото людей

Файл кладётся в `oneten-site/assets/people/` с именем слота, затем запускается `patch.py`. Пример: `assets/people/seo-team-1.jpg`. Подходят `.jpg`, `.png`, `.webp`, пропорции 4:5 (офис 4:3).

| Страница | Слоты |
|---|---|
| SEO | `seo-team-1..3` |
| Директ | `direct-team-1..3` |
| Лидогенерация | `leads-team-1..3` |
| Усиление ПФ | `pf-team-1..3` |
| Комплексный маркетинг | `complex-team-1..4` |
| Как мы работаем | `process-team-1..4` |
| Кейсы | `cases-team-1..4` |
| О компании, офис | `about-office-1..3` |
| Контакты, менеджер | `contacts-manager` |

Имена и должности меняются в `content.py` (`TEAM`, `GALLERY`, `MANAGER`). Сейчас там стоит «Фамилия Имя».

Слоты, которые были в макете раньше (`founder`, `home-team-*`, `about-*`, `articles-team-*`, `team-sites-*`, `case-*`, `contacts-map`), заполняются в Claude Design перетаскиванием картинки или атрибутом `src` у `<image-slot>`.
