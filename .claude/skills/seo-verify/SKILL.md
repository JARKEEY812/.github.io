# seo-verify

```bash
python3 .claude/skills/seo-verify/check.py <файл.html | папка> [...]
```

- `ERROR` — точно сломано (нет title, невалидный JSON-LD, noindex на странице). Код выхода 1.
- `WARN` — рекомендация, не правило. Решение принимать с учётом контекста.
- Пороги длины title/description — ориентиры: Google обрезает по ширине в пикселях, а не по символам, и может переписать сниппет сам.

Правило: сравнить вывод до и после правки. Если ERROR стало больше — правку откатить.

Скрипт не проверяет: реальный рендер JS, ответы сервера (коды, редиректы), дубли между страницами, соответствие разметки контенту. Это — `seo-auditor` / `seo-verifier`.
